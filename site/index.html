kirie — wallpaper compatibility

Wallpaper Engine items tested with kirie. Unless an image is badged Workshop preview, it is kirie's own render, captured with kirie --screenshot. Titles link to the item on Steam.

Report a wallpaper

Add or correct an entry

Don't want to touch the repo? Open a report — paste the Workshop link, say what happened, done. Running kirie list --json and pasting the output covers most of the form.

Sending a change yourself? Edit site/wallpapers.json on GitHub and open a pull request. Add a screenshot by dropping site/shots/<id>.jpg in the same PR — 960×540, and it must be kirie's own render (kirie --bg <dir> --screenshot out.png), not the Workshop preview art. This page redeploys on merge.

Reading the list from your own code? This page is only a viewer — the data is one static file, served with Access-Control-Allow-Origin: *, so fetch it directly: curl -s https://unhingedsoftware.github.io/kirie/wallpapers.json. Branch on the top-level schema field; it is bumped if the entry shape ever changes.

Statuses: works renders correctly · partial renders with visible problems (say which in notes) · broken fails to load or renders wrong · asset is an effect or preset used to build wallpapers, not a wallpaper itself.

Wallpapers are the work of their Workshop authors and are listed here only to document what kirie renders; each title links back to its page on Steam. If you are an author and want your item removed, open an issue and it will be taken down.
